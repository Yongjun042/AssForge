# 『絵馬に願ひを！』(Prologue Edition) 트레일러 — 일→한 .ass 자막 제작 지시서

> **AssForge 적용 개정판 v2** (2026-07-03 저장, docs/ema-trailer-seed.ass 와 세트)
> 이 개정판은 AssForge의 현재 편집·미리보기 범위에 맞춰 좌표 앵커, 폰트 고정,
> 모션 입력, 검수 절차를 명확히 한 작업용 문서다.

> **이 문서의 성격**
> 원본 영상(CWmcVS-xqhg)과 한글자막 영상(21kLOXHtQhI)을 **5,015 프레임 전량 픽셀 단위로 대조**하여, 자막 영상에 *추가된 픽셀만* 분리해 낸 뒤 위치·크기·색·투명도·움직임·페이드를 실측한 결과다. 아래 좌표·시간·색상 값은 **검출 결과의 기준값**이다.
> 대사/가사 텍스트 자체는 담지 않았다. 번역문은 작업자가 넣고, 이 문서는 **"어디에·어떤 모양으로·어떻게 움직이게"** 를 규정한다.
>
> 단, §5의 x/y/w/h는 렌더된 잉크의 바운딩 박스이고 Δ 열은 검출 구간의
> 관측 범위다. 이것만으로 모든 `\pos`/`\move`/`\t` 값을 역산할 수는 없다.
> 특히 움직이는 이벤트는 §4의 규칙과 원본 프레임 재측정을 함께 사용한다.
>
> **⚠ 좌표계 주의 — 반드시 먼저 읽을 것**
> 유튜브 트레일러 영상은 본편 화면 둘레에 장식 테두리(문양 틀·로고·자켓·하단 타이틀 밴드)가 둘러져 있고, 본편 화면은 그 안에 **75 % 크기로 축소되어** 들어가 있다.
> **이 문서의 모든 좌표는 그 테두리를 제거하고 본편 화면만 1920×1080으로 펼친 기준**이다. 즉 실제 작업 대상(테두리 없는 소스)에 그대로 넣으면 맞는다. 변환식은 §1.3에 있다.

## 0. 요약: 이 자막의 정체

이 영상은 **일본어 자막이 화면에 구워져(hardsub) 있다.** 한글자막 영상은 그 일본어를 지우지 않고, **바로 옆(위/아래/좌/우)에 한국어를 덧붙이는 방식**이다.

따라서 작업 목표는 "번역 자막을 얹는 것"이 아니라 —

> **원본에 이미 있는 일본어 타이포그래피의 스타일·크기·색·움직임을 그대로 흉내 낸 한국어 쌍둥이를, 그 옆에 붙이는 것**

이다. 이것이 유일한 대원칙이며, 아래 모든 규칙은 여기서 파생된다.

### 0.1 작업 시작 전 필수 입력

다음 항목이 모두 확정되기 전에는 픽셀 단위 본작업을 시작하지 않는다.

| 항목 | 필수 기록 |
|:--|:--|
| 테두리 없는 작업 소스 | 절대 경로, 파일 크기, SHA-256 |
| 비교용 원본·한글자막 영상 | 로컬 파일 경로, SHA-256 |
| 확정 번역문 | 씬/검출 그룹/어절 대응표 |
| 사용 폰트 | 실제 폰트 파일, 버전, SHA-256, 라이선스 |
| 렌더 환경 | FFmpeg·libass 버전, 사용한 fonts 디렉터리 |
| 납품물 | UTF-8 `.ass`, 사용 폰트 목록, 검수 로그 |

유튜브 ID만으로는 같은 디코드 결과를 보장할 수 없다. 픽셀 검수는 반드시
해시가 고정된 로컬 파일을 기준으로 한다.

## 1. 소스 사양과 좌표계

### 1.1 영상 스펙 (원본·자막본 동일, 프레임 완전 정렬)

| 항목 | 값 |
|:--|:--|
| 프레임레이트 | **24000/1001 = 23.976 fps** (1프레임 = 41.708 ms) |
| 총 프레임 | 5,015 |
| 길이 | 209.167 s (3분 29초) |
| 작업 기준 해상도 | **1920 × 1080** (테두리 없는 본편 화면) |

### 1.2 화면 구조 — 그냥 꽉 찬 1920×1080

별도의 영역 구분이 없다. 장식 테두리도, 상하단 밴드도, 안전영역 오프셋도 없다. 모든 `\pos` 값은 1920×1080 전체 화면 기준의 절대 좌표다.

### 1.3 트레일러 좌표 ↔ 작업 좌표 변환식 (측정 원본 추적용)

유튜브 트레일러 프레임에서 본편 화면은 **x 240–1679, y 135–944 (정확히 1440×810, 상하좌우 정중앙)** 에 놓여 있었다. 1920×1080의 정확히 **0.75배**다.

```
작업_x = (트레일러_x − 240) × 4/3
작업_y = (트레일러_y − 135) × 4/3
작업_크기 = 트레일러_크기 × 4/3        (폰트 크기·테두리 굵기·이동거리·속도 모두 포함)
```

* 검산: 트레일러 (240,135) → (0,0), (1679,944) → (1919,1079), 중앙 (960,540) → (960,540). ✔
* **이 문서에 적힌 값은 이미 변환이 끝난 값이다.** 다시 곱하지 말 것.

### 1.4 ASS Script Info (그대로 사용)

```ini
[Script Info]
Title: Ema ni Negai wo! - KR
ScriptType: v4.00+
WrapStyle: 2
ScaledBorderAndShadow: yes
YCbCr Matrix: TV.709
PlayResX: 1920
PlayResY: 1080
```

* `WrapStyle: 2` **필수** — 자동 줄바꿈을 끄고 `\N`만 줄바꿈으로 쓴다. 이 자막은 전부 `\pos`/`\move`로 절대 배치하므로 자동 줄바꿈이 개입하면 무너진다.
* `ScaledBorderAndShadow: yes` **필수** — 테두리/그림자가 PlayRes 기준으로 스케일되어야 재생 해상도가 달라도 동일하게 보인다.

### 1.5 AssForge 시작 파일 규칙

AssForge의 새 문서 기본값은 `WrapStyle: 0`이고, 현재 UI에서는 누락된 Script
Info 키를 새로 추가할 수 없다. 따라서 **빈 프로젝트에서 시작하지 말고**,
§1.4의 키와 §3의 스타일, Events 형식이 이미 들어 있는 시드 `.ass`를
먼저 만든 뒤 AssForge로 연다. → **`docs/ema-trailer-seed.ass` 가 그 시드다.**

AssForge 작업 규칙:

1. 정지 이벤트의 앵커 확인에는 `영상 위에서 비주얼 편집`을 사용할 수 있다.
   실제 글꼴·외곽선 크기는 프록시 표시가 아니라 mpv 라이브 미리보기로 판단한다.
2. `\move` 또는 `\t`가 있는 이벤트에는 `타이프세팅` 창을 적용하거나 위치를
   드래그하지 않는다. 현재 구현에서는 `\move`가 `\pos`로 바뀔 수 있으므로
   인스펙터의 원시 ASS 텍스트에서 직접 편집한다.
3. 이 작업은 측정값 재현이 목적이므로 `자동 효과 연출`은 사용하지 않는다.
4. 같은 시간에 여러 어절 이벤트가 존재하는 것은 정상이다. QA의 단순 시간
   겹침 경고는 해당 이벤트가 실제 화면에서 겹치는지 확인한 뒤 판정한다.
5. 폰트 누락은 AssForge QA에만 의존하지 말고 작업 시작 전에 수동 확인한다.

## 2. 배치 규칙

### 2.1 상단 내레이션 캡션 — **작업 대상 아님**

트레일러의 상단 홍보 문구는 본편 화면 바깥(장식 테두리 영역)에 있다. 작업
좌표로 환산하면 전부 화면 밖 음수(y −157 ~ −77)가 되므로 **테두리 없는
소스에는 이 문구 자체가 존재하지 않는다. 만들지 말 것.**

### 2.2 본편 자막 — 원문 대비 한국어의 위치 결정

| 원문 형태 | 한국어 위치 | 근거 (실측 예) |
|:--|:--|:--|
| 가로 1줄, 화면 상반부 | 바로 **아래** | t=115.9 |
| 가로 1줄, 화면 하반부 | 바로 **위** | t=28.4, t=46.0 |
| 가로 2줄 | 1줄은 위, 1줄은 아래로 분산 | t=185 |
| 가로 3~4줄 블록 | 위 2줄 + 아래 2줄로 분산 | t=200 |
| 우측 정렬 다단 스탠자 | 각 일본어 줄의 **왼쪽**에 우측정렬로 | t=121~127 |
| 세로쓰기 | 세로 컬럼의 좌 또는 우 (여백 쪽) | t=10 왼쪽 / t=138.7 오른쪽 |
| 대각선 계단 배치 | 각 글자의 **좌하단**에 1:1 | t=127~134 |
| 인라인 아이콘이 낀 줄 | 아이콘 자리를 비워 두고 어절만 대응 | t=155 |

### 2.3 어절 단위 분할 정렬 — 이 자막의 핵심 습관

한국어 한 줄을 하나의 이벤트로 쓰지 않는다. 원문 일본어를 어절/의미 덩어리로
쪼갠 뒤, 각 덩어리를 대응하는 일본어 덩어리의 바로 위·아래에 개별 `\pos`로
정렬한다. 최종 .ass의 Dialogue 줄 수는 번역 문장 수보다 2~4배 많아진다. 정상이다.

### 2.4 좌표와 앵커 규칙

§5의 `x, y, w, h`는 검출된 잉크 바운딩 박스의 좌상단과 크기다.
정지 이벤트의 기본 변환: `an5 중심 앵커 = (x + w/2, y + h/2)`.
이 값은 첫 배치용 초깃값이며, 실제 번역문을 렌더한 바운딩 박스가 표의 목표
위치에 오도록 조정한다. 세로 컬럼 상단 중앙 기준이면 `\an8`, 좌상단 고정이면
`\an7`을 명시. 움직이는 이벤트는 시작·종료점 모두 같은 `\an`.

### 2.5 글자 크기

한국어는 대응 일본어보다 작다 — 실측 비율 **0.85~0.88**. 씬마다 원문 잉크
높이를 직접 재서 목표 한국어 잉크 높이를 ×0.86으로 잡고, 렌더 후 `\fs`를
조정한다. 1440×810 트레일러 프레임에서 측정한 값만 4/3배 한다(이중 변환 금지).

## 4. 효과 카탈로그 — 실측값과 ASS 구현

### E1. 하드컷 (기본값)
`{\pos(1090,777)}텍스트` — 픽셀 0→4,706 이 1프레임에 점프. 페이드 넣지 말 것.

### E2. 페이드 인/아웃
실측 페이드는 **1프레임(42ms) 단위**: 42/83/**125(최빈)**/167/209/250,
씬 전환부 292~500, C-Faint 퇴장 542~918. 각 그룹의 실측값은 §5 표 마지막
두 열 → 시드의 `\fad`에 이미 반영됨. 그룹을 어절로 나누면 같은 값 공유.

### E3. 상향 스크롤 (C-Faint 씬 전용, t63–86)
**−8.03 px/frame = −192.5 px/s**, x 고정.
`{\move(529,945,529,559,0,2002)\fad(209,209)}` —
`y_end − y_start = −192.5 × 지속초`. §5의 Δx는 이동량으로 쓰지 않는다.
일본어 원문과 반드시 같은 속도.

### E4. 후퇴 줌아웃 (오프닝 전환)
정지 → 334ms 후퇴(×0.566 축소, 중심 (−360,+149) 이동) → 컷 아웃.
대표 예: `{\move(1831,376,1471,525,1460,1794)\t(1460,1794,\fscx57\fscy57)\fad(0,60)}`
`\move`와 `\t`의 시간 범위를 동일하게. 다른 S1 이벤트는 표에서 역산하지 말고
원본 프레임을 재측정해 작업 기록(그룹#/an/정지·종료 앵커/scale/t1·t2)을 채운다.

### E5. 세로쓰기 조판
`{\an8\pos(1662,28)\fs85}그{\N}아{\N}비...` — 한글은 회전하지 않는다.
줄간격 정밀 제어는 음절별 개별 `\pos`가 안전. (1662,28)은 상단 중앙 → `\an8` 필수.

### E6. 세로쓰기 원근 크기 그라데이션 (t134–143)
음절 잉크 높이 23→29→35→39→41→49px (≈+15%/음절). **음절=이벤트 1개** 필수.
y 간격도 크기에 비례해 커진다. 예: `{\an5\pos(1031,420)\fs29}로` ...

### E7. 대각선 계단 배치 (t127–134)
글자당 이벤트 1개, 일본어 글자 좌하단에 1:1. 주 대각선 5글자 an5 앵커:
#52(188,417) #53(399,548) #54(613,681) #55(721,749) #57(830,809).
1글자당 기본 스텝 (+107,+65). 글자 크기 60~65px. #56/#58은 전환 중 별도 그룹,
#59는 하단 긴 블록 — 계단에 합치지 않는다.

### E8. 어절별 색상 강조 (인라인)
원본 강조어와 같은 색을 같은 단어에. 주황(황금) = #F7B300 = `\c&H00B3F7&`.
붉은/푸른 강조는 해당 프레임에서 원본 글자 중심 픽셀을 스포이드로 추출.

### E9. 글로우 (t200–209)
`{\pos(1490,207)\c&H00B3F7&\3c&H0060C0&\blur8\bord5}노을`
필요 시 같은 위치에 `\blur27\bord16\alpha&HA0&` 광채 전용 이벤트를 Layer 0에
깔고 본문을 Layer 1에 올린다.

### E10. 반투명 (C-Faint)
`\1a&H8C&` (≈45% 불투명). 테두리·그림자 0.
근거: bg 191 위 관측 105 → 105/191≈0.55 → 불투명 0.45. 밝기 따라 &H80&~&H98&.

  앵커를 위로. 시드에는 cy=1037로 클램프해 두었다.
* 시작/종료는 센티초 반올림 작업값. 프레임 검수는 `frame = round(s × 24000/1001)`.
